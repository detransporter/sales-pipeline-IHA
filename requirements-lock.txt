# Exakt fungerande version av VARJE byggkloss (inklusive de som requirements.txt
# inte nämner direkt, t.ex. pandas/numpy under pandas). Skapad 2026-07-25 genom
# att installera requirements.txt i en helt ren, tom miljö och sedan "frysa"
# exakt vad pip valde — så en framtida installation aldrig råkar dra in en ny
# version som inte är testad.
#
# requirements.txt   = vad appen behöver (lösa "minst version X")   → normal drift
# requirements-lock.txt = EXAKT dessa versioner, inget annat        → trygg återinstallation
#
# Installera från den här filen (garanterat samma som testades):
#     pip install -r requirements-lock.txt
#
# Uppdatera låsfilen efter att requirements.txt ändrats OCH appen testats:
#     python3 -m venv /tmp/lock_venv && /tmp/lock_venv/bin/pip install -r requirements.txt \
#       && /tmp/lock_venv/bin/pip freeze > requirements-lock.txt && rm -rf /tmp/lock_venv
#     (spara sedan om denna kommentarrad överst — pip freeze skriver bara paketlistan)
